# planner/optimizer

优化器：对逻辑计划进行变换，生成更高效的计划。

## 职责

- 规则驱动优化（RBO）：
  - 谓词下推（Filter 下推到 Scan）
  - 列裁剪（只读取查询需要的列）
  - 常量折叠与表达式简化
- 代价驱动优化（CBO，可选扩展）：基于统计信息选择算子实现
- 输出优化后的逻辑计划，供 physical_plan 选择物理算子

## 设计要点

- 优化规则以"模式匹配 + 计划重写"形式组织，便于扩展
- 规则应用顺序与幂等性需明确（固定点迭代或有序 pass）
- 保留优化前后计划的可对比性，便于 EXPLAIN 展示优化效果
