# execution/vector

列式批（Batch）与向量化类型：执行引擎的数据载体。

## 职责

- 定义 `Batch`：一组列（Column）+ 行数，算子间数据传递的基本单位
- 定义列式内存布局：
  - 定长列：连续数组（i32/i64/f64 等）
  - 变长列：offsets + 字节串（string）
  - null 表示：validity bitmap
- 提供向量化表达式求值的基础类型与 SIMD 友好的访问接口

## 设计要点

- 批大小（batch size）固定（如 4096/8192 行），平衡缓存与吞吐
- 列数据零拷贝传递：算子间共享列引用，避免重复拷贝
- 为 SIMD 优化预留对齐与连续内存布局
