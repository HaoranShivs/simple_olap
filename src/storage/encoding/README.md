# storage/encoding

编码压缩：对 column_chunk 进行编码与压缩。

## 职责

- 提供多种编码策略：
  - RLE（游程编码）：适合低基数/重复值列
  - 字典编码：适合字符串/枚举类列
  - Delta 编码：适合单调递增列（如时间戳、自增 ID）
  - 位图编码：适合布尔列
- 编码/解码接口统一：`encode(values) -> bytes`、`decode(bytes, range) -> values`
- 根据列的统计特征自动选择编码方式

## 设计要点

- 编码选择可基于写入时的数据采样（基数、单调性）
- 解码支持按行范围部分解码，避免整列解码
- 压缩率与解码速度需权衡，benchmark 中对比各编码效果
